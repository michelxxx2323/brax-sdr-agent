Política de privacidade

BRAX SDR (P.H.) · atualizada em 7 de outubro de 2026 · sobre o projeto

A BRAX é uma empresa fictícia. O BRAX SDR é um projeto de portfólio: um assistente virtual de pré-vendas ("P.H.") que demonstra como qualificar contatos por WhatsApp e e-mail. Não há produto financeiro real, e nenhuma conta, cartão ou crédito é oferecido.

Quais dados usamos

Só o que a pessoa envia ao P.H.: o texto das mensagens, o nome e o número de WhatsApp ou o endereço de e-mail do remetente, e as informações sobre a empresa que ela decidir contar (nome, tamanho, gasto estimado, cargo). O P.H. nunca pede senhas, códigos, documentos ou dados de cartão.

Dados do Gmail

O BRAX SDR acessa apenas a caixa de e-mail da própria BRAX (brax.ph.sdr@gmail.com), para ler as mensagens recebidas de remetentes autorizados, responder na mesma conversa e marcar o que já foi atendido. Não acessa a caixa de nenhum outro usuário.

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado (Limited Use). Os dados do Gmail não são usados para publicidade, não são vendidos e não são usados para treinar modelos de IA.

Para que usamos

Para responder à pessoa, entender se a empresa dela tem o perfil atendido e registrar o atendimento. Nada além disso.

Onde os dados ficam

  • Anthropic (API do Claude): o texto da conversa é processado para gerar as respostas do P.H.
  • Supabase: banco de dados com o histórico de cada conversa.
  • HubSpot: CRM com o contato, a empresa e a etapa do atendimento.
  • Slack: resumos internos quando uma pessoa do time precisa aprovar ou assumir um atendimento.
  • Railway: servidor onde o P.H. roda.

Os dados não são vendidos nem compartilhados com terceiros além desses serviços.

Seus direitos (LGPD)

Se você pedir para parar, o P.H. para de enviar mensagens e registra o pedido. Para pedir acesso aos seus dados ou a exclusão deles, escreva para brax.ph.sdr@gmail.com.
